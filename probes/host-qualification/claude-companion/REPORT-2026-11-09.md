- Prompt asked for `sleep 40`. Haiku reported "The harness blocked the foreground sleep" and ran it in the BACKGROUND instead; events seen: `system/thinking_tokens`, `system/background_tasks_changed`, `system/task_started`, later `system/task_notification`, `system/task_updated`.

- stdin control request `{"type":"control_request","request_id":"int-1","request":{"subtype":"interrupt"}}` was ACKNOWLEDGED: `{"type":"control_response","response":{"subtype":"success","request_id":"int-1","response":{"still_queued":[]}}}`. So the control channel works in -p mode.

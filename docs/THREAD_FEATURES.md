# Features that must survive the thread redesign

Written before the 1.0.0 vocabulary: tools `agent_*` are now `companion_*`, and `target` is `companion`; see docs/VOCABULARY_PLAN.md.

Inventory taken 2026-11-22 from the code on main, each row checked against the
code, before any redesign work. It is the checklist for
[THREAD_PLAN.md](THREAD_PLAN.md): every row must still hold after the plan's last
step, changed only where the plan says so. "Depends on the subagent/owner model"
marks the rows the redesign touches. Paths are relative to the repo root. Mod
tests (`hooks/*.test.ts`) run under `claude plugin test`, not `node --test`.

After (2026-11-23) — 143 rows: 109 hold, 30 change by design (the table under Features in THREAD_PLAN.md), 4 never held on main either. Eleven holding rows keep a clause that no test pinned on main either, marked `unpinned (also on main)`; one of them has no pin at all.

The Copilot CLI 1.0.114 and Claude Code 2.1.330 history and message rows reflect measurements from 2026-11-23.

Always-on message box, like the companion's own app (v2)

Dummy data. The right side reads like Codex, Claude Code or OpenCode: transcript, live line, then an input box pinned to the bottom. When the job has focus, you type straight into the box. ⏎ sends in the mode shown on the box, which starts on that companion's own default; shift+⇥ switches mode, the way Claude Code cycles its modes.

Keys while a running job has focus

KeyActionWhy
typing, ⏎Write and send in the shown modeLike the provider apps
shift+⇥Next mode the companion supports (steer, queue, interrupt & send)Claude Code cycles modes with shift+⇥
ctrl+jNew line in the messageWorks in every terminal; shift+⏎ does not
↑↓, PgUp PgDnScroll the transcriptLetters now type, so scrolling moves off j/k
ctrl+oExpand or fold all outputsClaude Code's transcript toggle
ctrl+xCancel the job (asks once)
escBack to the job list; the draft is keptNever interrupts the companion by accident
ctrl+cClear the draft; on an empty box, quitLike Claude Code

On the job list and on ended jobs the existing single-letter keys stay: j k, / filter, o older, e expand, q quit.
